# Campos del Anexo I

Estos campos son opcionales en origen: si se desconocen se devuelven como `null` y la app solicita revisión. Nunca inferir una declaración negativa. Las claves corresponden a `data.declaration`. La app adaptará `null` a campo vacío.

| Clave | Significado |
|---|---|
| `actionName` | Nombre de la actuación (Actuación) |
| `sheet` | Código y nombre de la ficha (Actuación) |
| `region` | Comunidad autónoma (Actuación) |
| `address` | Dirección de la actuación (Actuación) |
| `cadastre` | Referencia catastral (o justificación de no aplicación) (Actuación) |
| `ownerName` | Nombre o razón social (Propietario) |
| `ownerNif` | NIF / NIE (Propietario) |
| `ownerAddress` | Domicilio (Propietario) |
| `ownerPhone` | Teléfono (Propietario) |
| `ownerEmail` | Correo electrónico (Propietario) |
| `beneficiaryName` | Nombre o razón social (Beneficiario) |
| `beneficiaryNif` | NIF / NIE (Beneficiario) |
| `beneficiaryAddress` | Domicilio (Beneficiario) |
| `beneficiaryPhone` | Teléfono (Beneficiario) |
| `beneficiaryEmail` | Correo electrónico (Beneficiario) |
| `representativeName` | Nombre o razón social (Representante) |
| `representativeNif` | NIF / NIE (Representante) |
| `representativeAddress` | Domicilio (Representante) |
| `representativePhone` | Teléfono (Representante) |
| `representativeEmail` | Correo electrónico (Representante) |
| `powerDate` | Fecha del poder notarial (Representante) |
| `powerNumber` | Número de protocolo (Representante) |
| `powerOther` | Título y fecha del documento de representación (Representante) |
| `aid1Program` | Programa de ayuda (Ayuda 1) |
| `aid1Agency` | Entidad u órgano gestor (Ayuda 1) |
| `aid1Year` | Año (Ayuda 1) |
| `aid1Rule` | Disposición reguladora (Ayuda 1) |
| `aid1Reference` | Número de expediente (Ayuda 1) |
| `aid1Status` | Estado de la concesión (Ayuda 1) |
| `aid1RequestedAt` | Fecha de solicitud (Ayuda 1) |
| `aid1ResolvedAt` | Fecha de resolución (Ayuda 1) |
| `aid1Amount` | Cuantía obtenida o esperada (€) (Ayuda 1) |
| `aid2Program` | Programa de ayuda (Ayuda 2) |
| `aid2Agency` | Entidad u órgano gestor (Ayuda 2) |
| `aid2Year` | Año (Ayuda 2) |
| `aid2Rule` | Disposición reguladora (Ayuda 2) |
| `aid2Reference` | Número de expediente (Ayuda 2) |
| `aid2Status` | Estado de la concesión (Ayuda 2) |
| `aid2RequestedAt` | Fecha de solicitud (Ayuda 2) |
| `aid2ResolvedAt` | Fecha de resolución (Ayuda 2) |
| `aid2Amount` | Cuantía obtenida o esperada (€) (Ayuda 2) |
| `place` | Localidad de firma (Firma) |
| `day` | Día (Firma) |
| `month` | Mes (en letras) (Firma) |
| `year` | Año (cuatro cifras) (Firma) |
