# Campos del Anexo I

Estos campos son opcionales en origen: si se desconocen se devuelven como `null` y la app solicita revisión. Nunca inferir una declaración negativa. Las claves corresponden a `data.declaration`. La app adaptará `null` a campo vacío.

| Clave | Significado |
|---|---|
| `region` | Comunidad autónoma (Actuación) |
| `address` | Dirección de la actuación (Actuación) |
| `cadastre` | Referencia catastral (o justificación de no aplicación) (Actuación) |
| `ownerName` | Nombre o razón social (Propietario del ahorro que puede ser Gestracking o su cliente) |
| `ownerNif` | NIF / NIE (Propietario del ahorro que puede ser Gestracking o su cliente) |
| `ownerAddress` | Domicilio (Propietario del ahorro que puede ser Gestracking o su cliente) |
| `ownerPhone` | Teléfono (Propietario del ahorro que puede ser Gestracking o su cliente) |
| `ownerEmail` | Correo electrónico (Propietario del ahorro que puede ser Gestracking o su cliente) |
| `beneficiaryName` | Nombre o razón social (del cliente de Gestracking) |
| `beneficiaryNif` | NIF / NIE (del cliente de Gestracking) |
| `beneficiaryAddress` | Domicilio (del cliente de Gestracking) |
| `beneficiaryPhone` | Teléfono (del cliente de Gestracking) |
| `beneficiaryEmail` | Correo electrónico (del cliente de Gestracking) |
| `representativeName` | Nombre o razón social (Representante del cliente de Gestracking) |
| `representativeNif` | NIF / NIE (Representante del cliente de Gestracking) |
| `representativeAddress` | Domicilio (Representante del cliente de Gestracking) |
| `representativePhone` | Teléfono (Representante del cliente de Gestracking) |
| `representativeEmail` | Correo electrónico (Representante del cliente de Gestracking) |
| `powerDate` | Fecha del poder notarial (Representante del cliente de Gestracking) |
| `powerNumber` | Número de protocolo (Representante del cliente de Gestracking) |
| `powerOther` | Título y fecha del documento de representación (Representante del cliente de Gestracking) |
|
