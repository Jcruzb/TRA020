# Anexo I original del Ministerio

Fuente: [MITECO, declaración responsable de ayudas y subvenciones](https://www.miteco.gob.es/content/dam/miteco/es/energia/files-1/Eficiencia/CAE/cat%C3%A1logo-vigente/Anexo%20I%20de%20las%20fichas_DR%20subvenciones.pdf).

Descargado el 23/09/2026. Cuatro páginas y 60 campos (texto, selección, casillas y firma). SHA-256 del original: `9e146ff2313fcedea4dc12c3b9c9e62b43423173e008dc378ebb8b232d5d9cf3`.

`anexo-i-miteco-original.pdf` se conserva sin modificar. `anexoTemplate.js` es su representación base64, generada por `npm run prepare:pdf`, para que las exportaciones funcionen sin red. No editarla a mano.

La aplicación carga el original, escribe los campos existentes y actualiza sus apariencias sin aplanar. El contenido gráfico de las páginas originales se conserva. Para flotas grandes añade una relación de equipos con campos editables. Al actualizar la fuente, revisar mapeo, apariencia, valores canónicos y widgets; no basta con cambiar el binario.
